Alarms

How reliable is this?

A browser alarm only fires while this page is open and the tablet is awake. Android will throttle or kill a backgrounded tab without warning.

Do not use this as a wake-up alarm. Use the tablet's own Clock app for anything you must not sleep through. This is for "stand up", "meeting in five", "tea is steeping".

Location & weather

Weather comes from Open-Meteo — free, no API key, no account, no tracking cookie. It receives a rounded latitude/longitude and nothing else. It is the only service this page contacts.

Calendar

Events you add here live in this browser's storage on this tablet. Nothing syncs, nothing uploads.

In Google Calendar: Settings → your calendar → Export. Drop the .ics here. Re-import whenever you want to refresh — imported events replace the previous import, your own stay put.

Google's secret .ics address will not work here. Google serves it without CORS headers, so the browser blocks the read. Only a feed whose server sends Access-Control-Allow-Origin (Nextcloud configured for it, or your own host) can be fetched. Use the file import above instead — it always works and keeps the URL off the network.
